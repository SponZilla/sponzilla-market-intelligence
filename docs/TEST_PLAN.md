# MVP Test Plan

Use 5–10 real companies covering different signal types:
- product launch
- expansion/store opening
- campaign
- sponsorship/event activity
- hiring/local activity

For each company verify:
1. input validation
2. sources are real and URLs retained
3. facts map to evidence
4. inference is explicitly labeled
5. no unsupported claims are produced
6. opportunity JSON matches schema
7. partial/provider failures are handled
